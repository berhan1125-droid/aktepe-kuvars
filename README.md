# Aktepe K.M.G. — Kuvars · Mermer · Granit

Aktepe Kuvars Mermer Granit için 3D tezgah stüdyosu web sitesi.

- `index.html` — tek sayfalık site
- `assets/js/app.js` — sayfa etkileşimleri (WhatsApp numarası dosyanın en üstünde)
- `assets/js/kitchen.js` — 3D mutfak sahnesi (three.js)
- `assets/js/stones.js` — taş dokusu üretici
- `assets/vendor/three.bundle.js` — three.js (MIT lisansı, `LICENSE-three.txt`)

GitHub Pages ile yayınlanır: Settings → Pages → Deploy from a branch → `main` / `(root)`.
